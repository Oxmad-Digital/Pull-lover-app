# Pull-Lover — Kit de refonte pour Codex

Ce dossier sert de référence visuelle et fonctionnelle pour appliquer la refonte au site e-commerce Pull-Lover existant.

## Contenu

- `PROMPT_CODEX.md` : prompt prêt à envoyer à Codex avec le dépôt du site ouvert.
- `DESIGN_SYSTEM.md` : règles graphiques, responsive et composants attendus.
- `reference/index.html` : maquette HTML interactive de référence.
- `reference/assets/` : visuels de la campagne et de l'atelier.

## Utilisation recommandée

1. Ouvrir le dépôt actuel de Pull-Lover dans Codex.
2. Ajouter ce dossier à la racine du projet, sous le nom `design-reference/pull-lover`.
3. Envoyer à Codex le contenu de `PROMPT_CODEX.md`.
4. Lui demander d'abord d'auditer l'architecture existante, puis d'implémenter la refonte par étapes.
5. Vérifier la home sur mobile et desktop avant de modifier les autres pages.

La maquette est une référence de direction artistique. Codex doit adapter son code au framework, aux composants et aux données réelles du projet : il ne doit pas copier aveuglément une page statique.

## Visuels

Les deux images du dossier `reference/assets` ont été générées pour cette maquette Pull-Lover et peuvent remplacer les images temporaires actuelles pendant l'intégration.
